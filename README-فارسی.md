# ArabiHamod — راهنمای انتشار

## انتشار روی GitHub Pages (یک بار)
۱. یک پوشه‌ی گیت‌هاب بساز به اسم `username.github.io` (اسم کاربری خودت به‌جای username)، حالت Public.
۲. تمام فایل‌ها و پوشه‌های همین بسته (`index.html`، `manifest.webmanifest`، `sw.js`، `videos-index.json`، پوشه‌ی `icons`، پوشه‌ی `videos`) را در ریشه‌ی همان پوشه آپلود کن. ساختار پوشه‌ها را دقیقاً حفظ کن.
۳. در Settings ← Pages، منبع را روی «Deploy from a branch» و شاخه را روی «main» بگذار.
۴. بعد از یکی دو دقیقه، سایت روی `https://username.github.io` بالا می‌آید.

## اضافه کردن ویدیوی جدید
۱. فایل داده‌ی ویدیوی جدید (مثلاً `videos/video2.json`) را که من می‌سازم، داخل پوشه‌ی `videos` آپلود کن.
۲. فایل `videos-index.json` را باز کن و یک آبجکت جدید داخل آرایه‌ی `videos` اضافه کن، درست مثل ویدیوی «camping». نمونه:
```json
{
  "slug": "video2",
  "file": "videos/video2.json",
  "emoji": "🎬",
  "title": { "ar": "...", "fa": "...", "en": "..." },
  "duration": { "ar": "...", "fa": "...", "en": "..." },
  "addedAt": "2026-10-01"
}
```
۳. مقدار بالای فایل، `updatedAt`، را به تاریخ همان روز تغییر بده.
۴. هر دو فایل را Commit کن. ویدیو خودکار با نشان «جدید» در صفحه‌ی اصلی ظاهر می‌شود، تا وقتی کسی بازش کند.

## تغییر لینک یوتیوب هر ویدیو
داخل فایل هر ویدیو (مثلاً `videos/camping.json`)، بخش `source` را ویرایش کن:
```json
"source": { "credit": "اسم سازنده‌ی اصلی", "originalUrl": "لینک ویدیوی اصلی", "myVideoUrl": "لینک ویدیوی خودت در کانال" }
```
اگر `myVideoUrl` خالی باشد، دکمه‌ی اصلی به لینک کانال یوتیوب (تنظیم‌شده در `index.html`) اشاره می‌کند.

## تغییر آیدی یوتیوب و تلگرام
داخل `index.html`، نزدیک بالای بخش اسکریپت، دنبال `CFG` بگرد:
```js
var CFG = {
  brand: 'ArabiHamod',
  youtube: 'https://www.youtube.com/@arabihamod',
  telegram: 'https://t.me/arabihamod',
  ...
};
```
لینک‌ها را با آدرس واقعی کانال و تلگرامت عوض کن.

## نکته‌ی مهم درباره‌ی به‌روزرسانی صفحه‌ی اصلی
مرورگر و Service Worker نسخه‌ی قبلی `index.html` را کش می‌کنند. بعد از هر تغییر در خود `index.html`، مرورگر کاربر با یک بار باز کردن دوباره‌ی سایت (وقتی آنلاین است) نسخه‌ی تازه را می‌گیرد. تغییری از طرف کاربر لازم نیست.
